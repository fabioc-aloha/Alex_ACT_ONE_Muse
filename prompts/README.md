# prompts/ — chat-ready prompts (Muse edition)

These 15 prompts come from the Copilot edition of Alex ACT ONE, where they ship
as slash commands. In this edition there is no slash-command loader — instead,
each file is a **chat-ready prompt you can paste into a conversation** with the
assistant to invoke the corresponding workflow.

| Prompt | What it starts |
| --- | --- |
| `assess-brain.prompt.md` | Audit which instructions/skills earn their context cost |
| `banner.prompt.md` | Generate an SVG banner |
| `bootstrap-core.prompt.md` | Activate the opt-in runtime modules deliberately |
| `bootstrap-project.prompt.md` | Scaffold a new repository with project guidance files |
| `compile-brain.prompt.md` | Consolidate session learnings into reusable form |
| `convert.prompt.md` | Convert between document formats |
| `critical-thinking.prompt.md` | Run the critical-thinking protocol on a decision |
| `install-visual-companions.prompt.md` | (Copilot-edition workflow; kept for reference) |
| `meditate.prompt.md` | Structured reflection pass |
| `problem-framing-audit.prompt.md` | Frame audit before solving |
| `render-chart.prompt.md` | Render a chart (Muse uses its native chart capabilities; see `docs/muse-capability-map.md`) |
| `rich-email.prompt.md` | Compose a formatted rich email |
| `setup-dependencies.prompt.md` | (Copilot-edition workflow; kept for reference) |
| `setup-enterprise.prompt.md` | (Copilot-edition workflow; kept for reference) |
| `status.prompt.md` | Produce a status report |

Prompts marked "Copilot-edition workflow" describe install/setup mechanics that
only exist in the Copilot edition; they are preserved for reference so the two
editions stay in sync.
